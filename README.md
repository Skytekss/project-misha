# Project Misha — ESports Analytics (Apple Keynote Special Edition)

> Премиальный, интерактивный веб-сайт — пародия на презентацию Apple Keynote для Миши в Лос-Анджелесе. Трансконтинентальный IT-альянс: **Тамбов × Los Angeles**.

## ✨ Особенности
- **Apple Aesthetics:** OLED Black (`#000000`), титановый акцент, матовое стекло (glassmorphism), Apple Intelligence glow.
- **5 интерактивных экранов:**
  1. **Hero:** Apple Keynote Intro, парящая эмблема ESports Analytics, чипы доверия.
  2. **Bento Grid:** 6 карточек с оффером («Крёстный отец App Store», «Гастро-дивиденды: Bar Rush ➔ Los Angeles», «Калифорнийский блат»).
  3. **Multiverse Simulator:** iOS Segmented Control (`Миша помог 🚀` vs `Миша отложил 😢`), шуточная убегающая кнопка по клику.
  4. **Official Agreement:** Чеклисты инвестора, быстрая отметка, динамическая электронная подпись *Misha Approved ✓*.
  5. **Titanium Certificate:** 3D-сертификат в стиле Apple Card / Black Titanium с наклоном за курсором и двойным залпом конфетти (`canvas-confetti`), прямая ссылка в Telegram для старта регистрации.
- **Mobile First:** Адаптировано под экраны iPhone и Telegram WebView, поддержка `safe-area-inset-bottom`, 60 FPS на GPU.

## 🛠 Стек технологий
- React 18 + TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React
- canvas-confetti
